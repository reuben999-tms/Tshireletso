        What the system does

        1. It builds a password with the browser’s secure random generator.
        2. It keeps only a salted PBKDF2 hash, never the password itself.
        3. Each login guess is hashed the same way and compared with the stored hash.
        4. Wrong guesses are logged. Every 3rd one locks the gate, and the 9th shuts the system down.

        Why lockouts work

        A computer can try thousands of guesses a second, so a short or common password falls fast. A lockout cuts that to a handful of guesses a minute, which turns a quick attack into one that takes years.

        Where the idea has limits

        Shutting everything down is a blunt tool. Anyone can fail nine times on purpose and take the system offline, which is called a denial of service. Real systems usually lock one account, add delays, and alert the owner. This demo also counts failures in your browser, so a refresh resets it. A real gate keeps the count on a server.

        Test with permission

        Every mission in the game is an authorised test. In real security work you only test a system with written permission from its owner. Testing without permission is illegal, even when you mean no harm.
